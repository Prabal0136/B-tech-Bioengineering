Student Grade Calculator 🎓
📌 Project Description

The Student Grade Calculator is a simple Python project designed for beginners.

This program asks the user to enter a student's name and marks in three subjects. It calculates the total marks, average marks, and final grade.

This project helps beginners understand basic Python programming concepts such as variables, user input, mathematical operations, conditional statements, and output.

🎯 Project Objectives
Learn basic Python programming.
Understand how to take user input.
Perform mathematical calculations.
Use conditional statements to assign grades.
Display results in a clear format.
Learn how to organize and upload a project to GitHub.
✨ Features
Accepts the student's name.
Takes marks for three subjects.
Calculates total marks.
Calculates average marks.
Assigns a grade based on the average.
Displays the student's result.

▶️ How to Run the Project
Step 1: Install Python

Download and install Python from the official website:

https://www.python.org/downloads/

Step 2: Download the Project

Download this repository or clone it using Git.

Step 3: Open the Project Folder

Open the project folder in your terminal or code editor.

Step 4: Run the Program

Execute the following command:

bash
python main.py


If your system uses the python3 command, run:

bash
python3 main.py

Step 5: Enter the Student Details

Enter the student's name and marks when prompted.

The program will display the total marks, average, and grade.

📊 Grading System
Average Marks	Grade
90–100	A
80–89.99	B
70–79.99	C
60–69.99	D
Below 60	F
